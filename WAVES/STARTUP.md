# Startup shell

- `index.html` shows one fixed, centered, full-viewport WaveS screen on every device: real local logo, name, subtitle, dot loader, status, and the required **Made by / Réalisé par CHETAINE YOUNES** credit pinned at the bottom (safe-area aware). It follows system light/dark preference; only the loader dots animate (static under reduced motion).
- Android: the launch theme uses the WaveS foreground icon on the same background colour (`res/values*/boot_colors.xml`) instead of the default Capacitor image, and both launch/app themes are full screen (no status bar, cutout area used), so there is no bar or colour flash before the web screen. Only `#startup-shell` receives inverse zoom when lazy CSS arrives, compensating the unchanged desktop body zoom (0.8 × 1.25 = 1).
- `public/startup.js` is deliberately a local **classic script**, not a module. It runs before the deferred entry, including when that entry cannot download. Vite's warning that this script cannot be bundled is expected: Vite copies it unchanged to `dist/startup.js`.
- `src/main.tsx` keeps the bundled fonts and starts the App import after two animation frames. `src/mountApp.tsx` owns React, App/styles imports and the existing crash boundary. This lets the HTML shell paint before App module evaluation, saved-state hydration and synchronous physics/sweeps without restructuring the solver.
- App's layout-effect callback signals an actual commit and removes the shell immediately: no root-child polling, minimum splash time or fade-out overlay. The render-error boundary also releases it when its existing reload/reset fallback commits.
- Eight seconds only updates the calm **Still loading… check connection** notice (translated in French): keep waiting, without retry, unmount, forced failure or automatic reload. A late commit immediately wins. Actual rejected imports or entry/stylesheet resource errors set `data-state="error"` and show a centered card with a ≥44px **Reload app / Recharger l’application** button. Reload preserves settings; nonessential image failures are ignored. The independent inline bilingual fallback still recovers if both bootstrap and entry are absent.
- The first simulation canvas has a separate, pointer-transparent preparing label in its drawing row until a successful draw. It never covers the scene toolbar or app controls. Paused/reduced-motion drawing retries a missing context.
